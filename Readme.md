## Hiya! This project is made to show how to download any last supported version of an specific app on the specific IOS version..for eg, IOS 14,15,etc
<br>
<br>
REQUIREMENTS:
<br>
-A Windows machine running Windows 7 above or a macbook with macOS High Sierra or before (the last system to fully support that specialized iTunes 12.6.5.3) or any Linux system(Preferably arch.)-Silicon macs can download that specific version of itunes with tools like Retroactive.
<br>
-An Iphone running IOS with internet connectivity.
<br>
-An apple ID.
<br>
